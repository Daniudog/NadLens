What's inside?

Signature feature — the heartbeat bar at the top of every page. An animated ECG-style canvas that draws Monad's live TPS as a waveform in real-time. Nobody else has this. It makes Monad's speed visceral the moment you land on the page.

Overview — 6 live stat cards (TPS, block number, txns, gas price, utilization, block time) + TPS area chart + gas utilization bar chart + latest block detail panel
Blocks — live block feed table updating every ~2 seconds as Monad produces new blocks
Wallet — address lookup for balance and transaction count, links to MonadVision
Charts — dedicated chart view with Phase 2 roadmap teaser

3 RPC fallbacks built in — rotates between Goldsky → Ankr → QuickNode automatically if one rate-limits.
That's it. No API keys. No environment variables. No backend — the app talks directly to Monad's public RPC from the browser.
